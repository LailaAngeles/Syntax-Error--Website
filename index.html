> SYSTEM CORE PURPOSE

Addressing key challenges faced by Grade 12 ICT C# Programming students and instructors.

Problem 01

Learning Pace & Syntax Confusion

Grade 12 ICT students often struggle with C# programming due to a lack of visual examples and slow learning pace. Complex blocks of code and frequent syntax errors cause distraction and loss of interest.

System Solution

Interactive Game-Based Learning

Provides interactive real-world challenges, syntax, and debugging exercises. This visual approach helps students retain concepts and creates a level playing field starting from Level 0.

Problem 02

Limited PC Access Outside School

Survey data indicates 40.3% of students lack personal computers at home, restricting practice strictly to 1.5 hours per week during lab classes and causing them to fall behind.

System Solution

Cross-Platform Mobile Application

Enables students to practice C# programming concepts directly on their smartphones anytime, anywhere—bridging the hardware accessibility gap for those without home PCs.

Problem 03

Limited Student Progress Tracking

Teachers at STI College Caloocan have limited ways to monitor programming proficiency, relying heavily on standard eLMS or pen-and-paper, which lack detailed real-time insights.

System Solution

Web-Based Analytics Portal

Integrates live web data analysis so instructors can monitor time spent per level and instantly identify students who are stuck on specific concepts.
